# ADR & rapports

> Ce dossier rassemble des décisions structurantes observées dans le code (ADRs « rétrospectifs ») et le rapport de vérification anti-hallucinations.

## Contenu

- [00_rapport_verification.md](00_rapport_verification.md) — rapport Verifier PASS/WARN/FAIL.
- [01_adr_choix_v8_slim_oauth2.md](01_adr_choix_v8_slim_oauth2.md) — ADR rétrospectif sur le choix Slim 3 + OAuth2 pour l'API V8.
- [02_adr_persistance_sugarbean.md](02_adr_persistance_sugarbean.md) — ADR rétrospectif sur l'ORM SugarBean et l'absence d'ORM tiers.

## Convention

Chaque ADR rétrospectif décrit :

1. **Contexte** — ce que le code montre sans interprétation.
2. **Décision implicite** — la décision lisible dans le code.
3. **Conséquences observées** — ce que cela engendre dans la base de code aujourd'hui.
4. **Preuves** — fichier:ligne.
